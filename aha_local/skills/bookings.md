# Bookings

1. Find the place's own booking page, or the system it links to (TheFork, OpenTable, SevenRooms, Resy). Confirm the branch if there are several.
2. Check availability for the exact date, time and party size before entering any details.
3. If that isn't free, tell the user the nearest options shown and ask.
4. Fill in their details from memories (name, phone, email, preferences).
5. Before the button that books, check the page's date, time and party size against the request. Fix any difference.
6. Book: you were asked, so click "Book" or "Confirm" without asking again. Ask only for something the request didn't cover: a deposit, a card guarantee, a fee, another time or price.
7. Read the confirmation page and report it as shown: venue, address, date, time, party size, name, reference, cancellation terms. No confirmation on screen: say so.
8. Add it to their calendar with the reference, unless they said not to.
